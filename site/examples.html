Each card below shows the exact source file under examples/, a badge for whether it compiled and ran, and the program's captured output. Reproduce the whole set with:

shell
python tools/verify.py --freak /path/to/freak
python tools/build_docs.py

The harness copies each example into a clean temporary directory, runs freak build with the default LLVM backend, executes the resulting binary, and records stdout verbatim. A failure is recorded with its diagnostics rather than hidden.
